# TMS-EEG Preprocessing Pipelines

This repository contains my personal submissions and assignments for the hands-on EEG preprocessing activity, completed as part of the course Brain Stimulation and Multimodal Electrophysiological Recording at CIMeC, University of Trento. 

This module of the course was supervised by Prof. Paolo Belardinelli (with hands-on sessions led by Matteo De Matola).

## Purpose & Scope

The primary objective of these assignments was to build, execute, and thoroughly evaluate a comprehensive EEG data preprocessing workflow:
* **Code Implementation & Execution:** Running provided Python code, adapting script components where necessary, and customizing parameter settings for effective signal cleaning.
* **Theoretical Integration:** Deepening the understanding of the physiological and physical origins of EEG artifacts and explaining the impact of each preprocessing step in an academic reporting style.
* **Advanced Preparation:** Serving as a practical foundation for advanced research and higher-level coursework.
